---
name: code_review
description: 审查工作区里的 Python 文件，先指出会出错的问题。
when-to-use: 用户要求审查代码、找 bug、看某个 .py 文件有没有问题，或问这段实现是否安全时。
---

先用 `read_file` 读用户点名的文件。用户没给路径时，用 `grep_search` 或 `list_files` 定位，再读相关文件。没读过的代码不要评论。

只写和当前代码有关的问题，按严重程度排列。每条包含：

- 严重程度：高、中、低
- 位置：文件和行号
- 问题：实际会怎样
- 改法：具体改哪一段

没有足以影响行为的问题时，直接写「没有发现会让功能出错的问题」，再补一条还没覆盖的测试或边界。
